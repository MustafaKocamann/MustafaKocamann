## About

I'm an **AI Engineer and Data Scientist** based in Turkey. I design, build, and ship intelligent systems end to end, from data exploration and predictive modeling to **agentic LLM applications** that run reliably in production.

My foundation is applied data science: CRISP-DM, RFM segmentation, fraud and leakage detection, predictive modeling, and **time series forecasting**. Today my focus is **agentic AI**: stateful multi-agent workflows, long-term agent memory, hybrid retrieval (vector + graph), systematic evaluation, observability, and AI safety.

> *Ship it, measure it, make it safe, then scale it.*
